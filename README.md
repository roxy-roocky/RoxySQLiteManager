# RoxySQLiteManager

> 🚧 **Work in progress**: this addon is currently in development

This addon lets you manage your SQLite database directly into Godot Editor. Open database, table managment, data vizualisation and inline edition.

## Dependancies

This addon cannot exists without [Godot SQLite plugin](https://github.com/2shady4u/godot-sqlite). Please take a look an give a ⭐️ star to this projet !

## Features

- [ ] Create / Edit / View tables
- [ ] Create / Edit / View indexes
- [ ] Create / Edit / View rows in table (inline)
- [ ] Truncate table
- [ ] Execute custom SQL query / script
  - [ ] From editor
  - [ ] From `.sql` file
  - [ ] From another SQLite database
- [ ] Export data to 
  - [ ] CSV
  - [ ] SQL Script
- [ ] Export table schéma to SQL script
- [ ] Import data from
  - [ ] SQL Script
  - [ ] CSV
- [ ] Additional content
  - [ ] Godot editor wide saved custom SQL queries/scripts to execute in opened database/table (custom action)
  - [ ] Use Godot CodeEdit capabilities to implements SQL autocompletion
